# GCSE Biology — Cells & Transport Revision Site

An interactive revision website covering the full **Cells & Transport** topic for GCSE Biology.

## What's included

- **5 topic sections** with notes, diagrams and tables
- **Interactive magnification calculator** with standard form output
- **Cell cycle stepper** — click through each stage
- **SA:V ratio calculator** — drag slider to see ratio change
- **Comparison diagrams** — prokaryotic vs eukaryotic, all three transport processes
- **Labelled SVG diagrams** — plant cell, bacterial cell, diffusion/osmosis/active transport

## Topics covered

1. Cell types (prokaryotic & eukaryotic, bacterial cell structures, animal & plant cells)
2. Microscopes & magnification (light vs electron, magnification formula, standard form, scale)
3. Cell division & specialisation (cell cycle, mitosis, differentiation, specialised cells)
4. Stem cells & cancer (sources, uses, ethics, benign vs malignant, risk factors)
5. Transport (diffusion, osmosis, active transport, SA:V ratio, exchange surfaces)

## Files

| File | Purpose |
|------|---------|
| `index.html` | Main HTML page — all content and SVG diagrams |
| `style.css` | All styling — colours, layout, responsive design |
| `app.js` | Interactive features — calculators, stepper, scroll nav |

## How to use

### Locally
1. Download all three files into the same folder
2. Open `index.html` in any browser — no server needed

### GitHub Pages (share with friends!)
1. Create a new GitHub repository
2. Upload all three files
3. Go to **Settings → Pages → Source → Deploy from branch (main)**
4. Your site will be live at `https://yourusername.github.io/your-repo-name`

## No dependencies
Pure HTML, CSS and vanilla JavaScript — no frameworks, no npm, no build step.
